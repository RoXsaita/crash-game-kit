# Export scope and privacy

## Included deliberately

- Finished native PowerPoint and offline HTML game in release assets; source checkouts rebuild them locally.
- Provider-independent Claude Code skill and detailed references.
- Portable source, tests, question JSON and build helpers.
- Only the generated backgrounds, props and character art belonging to this example, including raw generation outputs and processed images.
- Embedded/standalone rendered intro/portal clips, synthesised sounds and actual rendered screenshots.
- Third-party Three.js files with their original MIT licence.

## Excluded

- Original workstation paths, user identity in author metadata and local executable paths.
- Original repository history, private project instructions, other projects and unrelated skills.
- Tokens, credentials, accounts, cookies, browser profiles, chat/session logs, environment files and databases.
- Virtual environments, dependency caches, full render-frame sequences and proprietary fonts.
- Downloaded source TikTok video files or original laptop/room screenshots. Public source URLs are retained for attribution/context.

The prepared media is intentionally included because this is a reproducible game/artifact share, not an export of a private content system. It contains no personal photographs.

The exported PowerPoint generator reads the portable shared JSON bank rather than a duplicated inline bank, and its author metadata is generic. The HTML builder resolves Node on PATH. Asset preparation accepts a local font path or uses Pillow's bundled default. These are portability changes, not a replacement of the game behavior.

Any upload-management token is stored outside this public bundle. The public download URL is sufficient for recipients. Free file-host retention should not be treated as permanent archival storage.
